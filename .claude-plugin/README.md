# SolarTech Claude Skills

Shared Claude Code skills for the SolarTech org.

## Install

Run once, in any repo, in your terminal:

/plugin marketplace add solartech-sd/claude-skills
/plugin install solartech-brand@solartech-skills

After that, the `solartech-brand` skill is available in every Claude Code session on your machine.

## What's included

- **solartech-brand** — colors, typography, logo usage, voice/tone, and writing rules from the SolarTech 2026 Branding Guidelines
